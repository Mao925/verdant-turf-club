# VERDANT — ターフクラブ

日本語で遊べる3D競馬ゲーム。Vite・JavaScript・Three.jsを使用しています。
8頭から単勝を1頭購入し、約36〜43秒のレースを観戦します。APIキー、有料サービス、外部モデルは不要です。

## 起動

Node.js 22.12以上を推奨します。

```sh
npm install
npm run dev
```

ターミナルに表示されるURL（通常 `http://localhost:5173/`）をブラウザで開いてください。スマートフォンからは同じWi-Fiに接続し、ターミナルの `Network` URLを開きます。端末によってはOSのファイアウォール設定が必要です。

```sh
npm test          # シミュレーション・保存・購入・払戻の自動テスト
npm run build    # dist/ に静的ファイルを作成
npm run preview  # ビルド済みファイルをローカルで確認
```

`dist/` は静的Webサーバーで配信できます。ファイルを直接ダブルクリックする `file://` ではなく、HTTP経由で起動してください。依存パッケージの初回インストールには通信が必要ですが、ゲーム実行時の画像・フォント・モデル・音声の外部ダウンロードはありません。

## Vercelへのデプロイ

公開URL：**https://verdant-turf-club.vercel.app/**

Vercelプロジェクト：`verdant-turf-club`。この作業フォルダは `.vercel/project.json` で関連付け済みです。

2026-09-05に本番デプロイ完了。公開URLのHTTP 200、Chromeでの3D表示・馬選択・購入ボタン有効化、コンソールエラーなしを確認しました。

`vercel.json` にVite・`npm ci`・`npm run build`・出力先 `dist` を設定しています。サーバーや環境変数は不要です。`.vercelignore` でローカルの生成物・検証用ファイル・環境変数ファイルをアップロード対象から除外しています。

```sh
npx --yes vercel login  # 初回のVercelログイン
npx --yes vercel --prod # 初回はアカウントと新規プロジェクトを選択
```

初回の関連付け後は、同じフォルダで `npx --yes vercel --prod` を実行すると更新できます。手順の出典：[Vercel公式CLIデプロイガイド](https://vercel.com/docs/projects/deploy-from-cli)。

コインは配信元ごとのブラウザ保存です。ローカルからVercelのURLに移ると、Vercel側では10,000コインから始まります。継続して遊ぶときは、毎回変わるデプロイ固有URLではなく、固定のプロジェクトURLを使用してください。

## 遊び方

1. 出走表から1頭を選びます。馬番・毛色・騎手の勝負服で識別できます。
2. 購入コインを100単位で入力します。初期所持金は10,000コイン。所持金を超える購入はできません。
3. 「購入してレース開始」で購入が確定し、3秒のカウントダウン後に発走します。
4. 金色のリングと矢印が購入した馬の目印です。進行状況・残り距離・8頭の現在順位を確認できます。
5. 選んだ馬が1着なら、`floor(購入額 × 確定オッズ)` コインを払い戻します。払戻には購入額を含みます。
6. 結果画面の「次のレースへ」で次の出走表に進みます。

### カメラと画質

| 操作 | 動作 |
| --- | --- |
| 追従 / キー `1` | 選択した馬を斜め後方から追います。未選択時は先頭馬が対象です。 |
| 俯瞰 / キー `2` | 隊列の広がりに応じて高さを変え、全体を見渡します。 |
| 中継 / キー `3` | 外側から隊列を追い、観客席付近では視点を上げます。 |
| `♪` | ローカル生成の発走・ゴール音をオン／オフ。初期状態はオフです。 |
| `⛶` | 映像を全画面にします。非対応ブラウザではページ内拡大を使用します。 |
| 高画質 | 2048pxの影、描画ピクセル比は最大1.75 |
| 標準 | 1024pxの影、描画ピクセル比は最大1.2 |
| 軽量 | 動的な影を無効化し、描画ピクセル比を最大0.85に制限 |

画質を下げても順位の計算は変わりません。馬の足元の簡易影は軽量でも表示します。

### 能力・脚質・オッズ

スピード、スタミナ、当日の調子、脚質、レース固有の運を速度に反映します。逃げは序盤、先行は前半の好位置、差し・追込は終盤で有利になる傾向があります。進路が塞がると減速し、安全な空間があれば横移動して追い抜きます。

オッズは能力と調子の相対値から推定したゲーム内数値です。実際の競馬のオッズや実証された的中確率ではありません。馬名・レース名・競馬場は架空です。

## 保存と整合性

- `localStorage` の `verdant-turf-v1` に、所持金、出走表、購入内容、レースの乱数シード、開始時刻、直近10レース、画質を保存します。
- 初回の出走表もすぐに保存し、表示中の馬と購入時の能力・オッズを一致させます。
- 購入内容とコイン控除を1つの保存操作で確定してから映像を開始します。保存に失敗した購入ではコインを減らしません。
- 購入後は馬・購入額・オッズを変更できません。開始処理のロックと購入状態の検査で連打を防ぎます。
- 購入IDを確認して払戻と履歴を1回だけ保存します。Web Locks対応ブラウザでは、複数タブの購入・払戻も同じロックで直列化します。
- 再読み込み時は保存したシードから同じレースを復元し、実時間に対応する位置から再開します。ページを閉じていた間に終了したレースも、次に開いた時に一度だけ精算します。
- レースは固定60Hzで事前計算し、映像はその同じ結果を補間表示します。ゴールを跨ぐステップ内で到達時刻を補間し、確定着順にも使用します。鼻先の表示位置は胴体・首のアニメーションに合わせて補正します。
- `データをリセット` は確認画面を表示します。確定すると進行中の購入を含むデータを削除し、10,000コインから再開します。100コイン未満でもリセットで遊び直せます。
- 保存先はブラウザと配信元ごとに別です。プライベートブラウズやサイトデータ削除では保存が消える場合があります。Web Locksがない古いブラウザでは単一タブでの利用を想定しています。

## 3D・使用素材

外部の画像、3Dモデル、音声、Webフォントは使用していません。

- 馬・騎手：本プロジェクト内で生成した立体メッシュ。胴体、首、頭、関節付きの4脚、たてがみ、尾、鞍、手綱、勝負服を含みます。
- アニメーション：進行距離と速度から脚の動き、膝の曲がり、胴体の上下動、騎手の姿勢、尾の揺れを生成します。
- 競馬場：芝のオーバルコース、内外の白い柵、開閉ゲート、ゴール板、観客席、観客、樹木、池、雲をコードで生成します。
- 番号・看板・草の粒・接地影：Canvas / DataTextureで生成します。
- 音：Web Audio APIによる合成音。文字は端末のシステムフォントで表示します。
- [Three.js](https://threejs.org/)：MITライセンス。ライセンス原文は `node_modules/three/LICENSE`。実装時に [WebGLRenderer公式ドキュメント](https://threejs.org/docs/pages/WebGLRenderer.html) を参照しました。
- [Vite](https://vite.dev/)：MITライセンス。ライセンス原文は `node_modules/vite/LICENSE.md`。

WebGLの初期化・読み込み失敗時とコンテキスト喪失時には、日本語のエラーと再読み込み案内を表示します。

## 検証

`npm test` の13テストが成功。シードを変えた複数レースの所要時間、再現性、異なる描画頻度、ゴール判定、接触回避、脚質・運の影響、購入拒否、二重控除・二重払戻、履歴10件、保存失敗と破損データを検証しています。

Chromeの実画面で次を確認しました。

- 3D競馬場、8頭の馬と騎手、走行アニメーション、3種類のカメラ。
- 未選択、150コイン、所持金超過で開始不可。開始ボタンをダブルクリックしても500コインの控除は1回のみ。
- レース途中の再読み込みで同じ馬・購入額・オッズ・残高を復元。
- 的中：500 × 2.4 = 1,200コインを払い戻し、残高10,700。画面内順位・確定着順・払戻の1着馬が一致。
- 不的中：100コイン購入・払戻0、残高10,600。2つのタブで同じレースと残高を復元し、履歴は1レースにつき1件。
- 結果後の再読み込みでも重複払戻なし。「次のレースへ」のダブルクリックでも1レースだけ進行。
- スマートフォン幅390pxで横はみ出しなし。馬・金額の選択、購入、追従／俯瞰カメラ、軽量画質を操作。
- リセット確認のキャンセルで結果を維持、確定で10,000コイン・第1レースに復帰。映像の全画面表示と解除も確認。
- 実画面で確認した範囲ではコンソールエラーなし。

スマートフォン実機、Safari/Firefox、実際のGPUコンテキスト喪失・保存容量超過のブラウザ再現、長時間の連続プレイは未確認です。保存失敗の処理は自動テストで確認しています。

## ファイル

- `src/main.js`：日本語UI・画面遷移・観戦表示・保存の接続。
- `src/scene.js`：WebGL描画、モデル、アニメーション、カメラ、画質。
- `src/simulation.js`：出走表、オッズ、固定ステップレース、補間。
- `src/store.js`：購入、控除、精算、復元、履歴、リセット。
- `src/style.css`：PC・スマートフォン対応の画面デザイン。
- `tests/game.test.js`：13件の自動テスト。
